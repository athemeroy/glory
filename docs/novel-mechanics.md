# 原著机制核对与本作实现

核对日期：2026-10-03。以下用原著章节确认行为，用读者整理寻找线索；持续时间、伤害、射速、体积和体力数值除特别说明外属于本作配置。没有把同人小说或其他授权手游的规则当成《全职高手》原著。

| 机制 | 核对结果 | 本轮实现 |
| --- | --- | --- |
| 抛沙 | 正面眼部命中才可能致盲，转头或改变视角能回避；失明看不到场景 | 实际头部接触加来沙方向判定，黑屏、移除锁定和目标提示；本作选择稳定4秒版本 |
| 遮影步 | 维持浮空目标的视角死角，是操作战术 | 真实视角、俯仰、高低差和遮挡判断；对手看见攻击者或浮空结束即停止；墙后躲藏不计作遮影步 |
| 神圣之火 | 持续伤害附带技能封印；封印期间仍可普通攻击 | 5秒区域、3秒技能封印，阻止技能和冷却消费；每次区域对目标只施加一次状态 |
| 眩晕与僵直 | 眩晕受击解除，动作产生的僵直另算 | 独立异常状态和物理受击状态，板砖头部命中致晕 |
| 混乱 | 操作指令方向混乱，角色并非自动失控 | 定时变化的输入方向映射，静止输入保持静止 |
| 束缚 | 约束移动，与所有行动被禁止有区别 | 禁止移动、跳跃、闪避、瞬移，保留攻击 |
| 冻结 | 冰块限制行动 | 禁止动作与移动、冻结当前骨架姿态、可净化；当前冰冻药水是本作原有技能的扩展 |
| 睡眠 | 催眠使目标沉睡，正面施法有效 | 新增催眠，背身无效；受伤醒来为本作明确规则，不宣称所有原著技能都有此规则 |
| 暗影烈焰 | 附着后的状态伤害可以打断吟唱 | 6秒灼烧、每2秒一跳，在读条时打断 |
| 圣诫之光 | 6秒承伤提高30% | 独立承伤状态，可净化 |
| 毒针 | 出血与破甲，不能仅凭技能名字判断是中毒 | 钢针、出血与破甲分别处理；本作5秒、25%承伤增幅 |
| 霸体与无敌 | 霸体抗击退僵直，仍受伤；抓取能克制霸体 | 伤害与物理控制分开；真实接触的抓取可破霸体，无敌免伤和异常 |
| 圆舞棍 | 有强制倒地、不可受身的特点 | 末击强制倒地，禁用落地受身 |
| 通用体力 | 疾跑、翻滚、跳跃会消耗体力 | 独立体力条、职业容量、通用动作消费、停跑恢复、耗尽后的恢复门槛 |
| 立体空间 | 技能需要操作、指引方向，视野与距离参与攻防 | 骨架分区胶囊、实际刀刃/拳脚扫掠、枪口起射、连续弹道、墙体先阻挡；不以二维距离代替接触 |
