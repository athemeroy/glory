# 战斗法师：炫纹与斗者意志

本轮将“对浮空目标额外 10% 伤害”的简化被动替换为实际炫纹资源循环和连击成长，并将误作独立技能的“龙抬头”按钮替换为二段矛刺“连突”。龙抬头在原著中是伏龙翔天的操作技巧；本轮没有声称已经实现该技巧的完整手操轨迹。

## 核对依据

- 蝴蝶蓝《全职高手》第 689 章“也是来偷袭的”：五属性炫纹由相应前置攻击命中产生，再次命中后才能发射；炫纹命中可累计连击，从而提升斗者意志。依据[章节正文](https://www.kunnu8.com/quanzhigaoshou/73448.htm)。
- 第 796 章“战斗法师的内战”：龙牙生成无属性、连突生成冰属性；招架也被视作有效命中，因此可以产生炫纹。冰炫纹命中后的自身增益为物防，无属性为移动能力；该章还明确炫纹互撞可触发增益。依据[章节正文索引](https://cn.ttkan.co/novel/pagea/quanzhigaoshou-hudielan_796.html)。
- 第 271 章“第七阶段的斗者意志”：七阶需要 120 连击；技能没有独立冷却与固定持续时间，每轮按连击成果结算。新一轮开始可继承先前高阶，但本轮连击中断后按本轮结果重新结算。依据[章节正文](https://www.hetubook.com/book/171/118553.html)。
- 第 28 章“职业水准的”：连突为两次突刺，同一位置命中有概率造成出血，骷髅不受出血影响。依据[章节正文索引](https://cn.ttkan.co/novel/pagea/quanzhigaoshou-hudielan_28.html)。

本轮检索主动排除了标题带“同人”“归来仍是少年”“从零开始”等衍生创作，以免将其他作者的补设定当成原作。

## 实际玩法

| 前置技能 | 生成炫纹 | 本作命中增益 |
|---|---|---|
| 龙牙 | 无属性 | 移速 +10% |
| 天击 | 光 | 动作速度 +8% |
| 连突 | 冰 | 受到物理伤害 -10%；使目标短暂减速 |
| 落花掌 | 火 | 物理伤害 +10% |
| 圆舞棍 | 暗 | 暴击率 +8 个百分点 |

前置技能必须真实接触对方身体或被对方成功格挡；挥空没有炫纹。一次技能最多产生一枚，包含圆舞棍、连突这样的多段技能。普通攻击可在后续命中时打开已储存炫纹的发射窗口。

鼠标右键或触控“炫纹发射”按钮手动发射最早可发射的一枚。刚由当前命中生成的球，必须等后续命中才具备发射资格。按住按钮不自动连发；没有球或没有命中窗口时有清楚反馈。AI 也按相同资格主动选择发射。

炫纹真实显示在背后，发射从对应小球所在位置开始，朝最近命中的目标飞行。它使用现有实体投射物系统，会撞墙、被身体挡住、受射程限制；撞墙不会触发增益。增益要等弹体实际命中后获得。起点到人物身体之间也检查墙体，避免背后小球伸到墙外后穿墙发射。

连突有两个独立的动作和真实武器接触窗口，并非一次矛刺算两份伤害。只有两次命中同一角色的同一身体分区，且目标局部坐标中的命中点相距不超过 0.18 米时，才按 50% 概率附加出血；角色数据的 `statusImmunities` 可明确拒绝此状态。

斗者意志与游戏原有伤害连击判定共用计数，不通过挥空、伤害为零或持续伤害增长。阈值为 10/20/30/40/50/60/120 连击。每轮结束结算当前阶数，新一轮重新计数。原先高阶不能靠不断重新开始一击永远维持；新短连击结束就会掉阶。受击打断会结束当前连击，不能沿用旧计数。

## 参数归属与范围

七枚储存上限、20 秒储存时间、1.2 秒发射窗口、0.24 秒发射冷却、18 米射程、炫纹伤害 30–42、增益持续 8 秒、上表百分比，均为本作平衡参数，未当作原著公开数据。暗炫纹的具体暴击增益是本作属性映射；本轮未找到足够直接的原文章节支持原著中的同一数值或规则。

意志移速按每阶 2%，七阶 24%；攻速与伤害以本作现有无“力量/武器攻速”面板的规则折算，每阶动作速度 +2%、物理伤害 +2.5%。本轮实现到可核实的七阶；75 级第八阶、炫纹之间的相互拦截、可定制炫纹发射顺序和完整手操龙抬头仍未实现。普通跳跃、闪避、防御性位移继续可用，原右键“矛挡”让位给职业核心的炫纹手动操作。

## 接口与检查

HUD 读取 `f.chasers` 的 `type/id/ttl/bornHit`，以及 `f.chaserHitSerial`、`f.chaserWindow`、`f.chaserCd`、`f.battleWill = { tier, combo, timer, carry, active }`。只有 `bornHit < chaserHitSerial` 的球可以利用当前窗口发射。LAN 快照保留这些资格信息，避免客机按钮提前显示可用。

`tools/check-battle-mage.py` 加载真实优化模型和真实 Fighter/Combat，在 Mini Chrome/Metal 中完成 49 项检查，全部通过且无浏览器错误。覆盖五招接触、连突两段、实体炫纹与墙体、五类增益、意志跨轮结算、同点出血/免疫、联机状态序列化与实际键鼠输入。连突在 2 米距离的两个实际接触点均落在胸腹区，彼此相距约 0.029 米；手动发射的弹体出生点与显示小球世界坐标误差为零。报告在 `../artifacts/battle-mage/results.json`。

真实两端 LAN 另由 `tools/check-lan-class-mechanics.py` 验证主机魔道学者飞行与客机战法输入/生成/发射/命中增益及清理，全部通过，两端角色生命值一致且浏览器无错误。该检查还捕获并修复了客机重放命中反馈时重复生成炫纹的问题：职业资源只在主机推进，客机只读取快照。报告与三张双端实测图在 `../artifacts/battle-mage/lan-class-mechanics-final/`。
