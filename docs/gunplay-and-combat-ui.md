# 枪系与战斗界面

这次界面按实际战斗优先级重排：桌面左下生命/法力/体力、中央底部技能热键、顶部比分与可见目标；手机保留六常规技能和大招，右下普攻放大，格挡/瞄准与跳跃/闪避分别分组，左下摇杆与疾跑。全屏、数据、观察目标、关卡目标收进“更多”，主视野保持空白。人物职业摘要实时显示扫帚飞行、召唤数量/指令、炫纹与斗者意志；长施法显示实际前摇读条，缺蓝和技能封印给出原因。

`T` / 触控“观察”默认仅选择血条，不带动视角。练习辅助跟随需在设置中主动开启 `aimAssist`，默认 `false`；实际命中仍由枪口和真实瞄准决定。

## 原著依据与实现边界

- [第77章《直接飞过去》](https://www.hetushu.com/book/171/118359.html)：君莫笑跳起、空中转身，借枪械后坐移动；后坐更大的武器能提供更强位移。对应实际出膛的三维反向冲量，不设置一个自动飞到目标的技能。
- [第104章《押枪神技》](https://www.hetushu.com/book/171/118386.html)：押枪需要连续击中浮空目标的合适位置。这里保留真实弹丸轨迹、接触与已有击退；没有添加自动追踪命中。
- [第180章《最快的枪炮师》](https://www.hetushu.com/book/171/118462.html)：强火力的后坐与后退卸力。当前重炮与激光出膛后坐较大、地面后退操作会减轻身体位移；没有宣称完整实现原文未卸力倒地惩罚。
- [第1203章《武川道的酒肆》](https://loying.org/book/quanzhi/43511.html)：枪炮师跳起后开炮拉开距离。空中射击用实际俯仰产生水平与垂直分量，故向下开枪可上托、向上开枪会向下压。

原著没有为本项目提供“米/秒”弹道参数。以下全部是本作参数，弹道下坠是本轮用户要求的玩法取舍，不伪称小说原值。

|类别|重力|空中水平冲量|抬枪幅度|说明|
|---|---:|---:|---:|---|
|双枪实体弹|9.8 m/s²|2.2 m/s|0.48°|瞄准降低后坐，仍需自行压枪|
|千机伞枪形态|9.8 m/s²|3.7 m/s|0.68°|大于双枪的借力|
|重炮实体弹|4.5 m/s²|7.6 m/s|1.8°|速度较慢，因此距离越远越需要抬炮口|
|枪炮师激光|0|8.2 m/s|1.65°|能量束保持直线，仍有发射后坐|
|法术、炫纹、召唤兽|各招式定义|不套用枪械冲量|不套用枪械抬枪|也不再冒橙色金属枪口火焰|
|手雷、瓶子、飞刀|各招式定义|不套用枪械冲量|不套用枪械抬枪|保留原有抛物线/引信/反弹|

同一帧的散弹只累计一次后坐。空中水平速度限制为18 m/s，射击抬升速度限制为8 m/s；开枪不取消重力，不能靠免费普攻无限悬停。地面后退操作减弱身体后坐，冻结/束缚不能通过开枪绕过移动控制。炮管穿墙时仍在墙前生成阻挡命中，子弹经过真实连续轨迹检查。

网络主机负责弹道和身体位移；访客重放枪口与本地抬枪反馈，后坐后的新瞄准角度由正常输入回传，避免把位移在两端再算一次。准星扩张只是射击反馈，真实命中不因此扩大。
