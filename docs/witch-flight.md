# 魔道学者：扫把掌握

本轮把魔道学者原先仅有的短时“扫帚冲刺”，补成独立于技能栏的骑帚飞行被动。玩家、AI 和联机主机使用同一 Fighter 物理与碰撞流程；客机按权威快照显示。

## 原著依据

- 蝴蝶蓝《全职高手》第 125 章“杰希大神”：扫把掌握使魔道学者可以骑帚飞行并在空中连续攻击；它是无冷却的被动能力，但飞行并非无限，飞行中断后需要触地才能再次骑帚。该章还出现向上斜飞、改变方向与飞行投掷药粉。本文依据可访问的[章节正文](https://www.hetubook.com/book/171/118407.html)核对，未采用同人续作的设定。
- 第 1345 章“合击”：王不留行中了神圣之火的技能封印期间失去扫把掌握的飞行能力，封印解除后再以变向、低飞和斜飞躲避追击。见[章节正文](https://www.69shuba.com/txt/1155/4925163)。
- 代表银武名称修正为“灭绝星尘”；此前界面误写成了其他职业的银武。

## 本作操作与平衡值

| 行为 | 键鼠默认操作 | 触控 |
|---|---|---|
| 普通跳跃 | 空格一次 | 跳跃按钮一次 |
| 起飞 | 空中再按空格 | 空中再按跳跃，按钮显示骑帚 |
| 上升 | 按住空格 | 按住上升 |
| 缓降 | 松开空格 | 松开上升 |
| 收帚 | Shift | 闪避按钮，飞行时显示收帚 |

起飞需要 8 点体力，飞行每秒消耗 14 点；普通跳跃仍消耗 12 点。一次飞行最多 5.5 秒，最多高于本次起跳地面 4.2 米，平移速度为基础速度的 1.2 倍。按住上升速度 3.1 米/秒，松开缓降 0.85 米/秒，均有速度平滑。这些参数是本作平衡配置，不宣称是原著公开数值。

收帚、体力耗尽、达到时限或被控制后，触地前不能再次起飞。普通受击遵守已有的硬直/浮空流程；霸体只承受伤害时不会无故掉落。技能封印、冻结、睡眠、眩晕、束缚、定身和恐惧会中断飞行。飞行并不获得无敌，也不放宽任何命中体积或攻击高度。

保留真实墙体、屋顶与地面碰撞；飞行上限固定在起跳位置，沿斜坡飞行不会无限抬升上限。职业技能可空中释放，原本不能移动施法的动作仍会停止水平主动移动。施法中的上升/缓降仍由同一飞行状态控制，投射物重力仍由投射物系统独立处理。

## 接口

`f.flightActive` 与 `f.flight = { active, used, elapsed, floor, maxDuration, maxHeight, reason }` 给 HUD 读取；`f.jumpHeld` 为持续上升输入，`f.wantJump` 仍为按下事件，`f.wantDash` 在飞行时收帚。状态不是额外的 `Fighter.state`，避免破坏施法和受击状态机。

LAN 的输入增加 `jump` 按住位；角色快照增加 `fl`。300 毫秒没收到远端输入后会释放上升。回合重置清空飞行状态和按住输入。没有 `fl` 的旧快照安全地回到非飞行状态。

## 验证

`tools/check-witch-flight.py` 在 Mini 的真实 Chrome/Metal 中加载默认优化模型，调用 `tools/check-witch-flight.js` 对实际 Fighter、World 和网络入口运行 46 项回归。覆盖普通跳跃、起飞/收帚/再起飞、不同帧率的时限、体力、控制、真实受击与霸体、薄墙/屋顶、全部 7 个技能空中释放、实际骑帚骨骼姿势、AI、LAN 输入与快照、其他职业不获得飞行。

运行：`python tools/check-witch-flight.py http://192.168.31.6:8780 <output>`。

本轮飞行动作使用既有真实绑定骨骼与双臂 IK，镜面和第一人称共享同一姿势；没有新造一套与世界模型脱节的第一人称手。

`tools/check-lan-class-mechanics.py` 的两个独立浏览器另实测了主机起飞/持续上升/耗体力与客机所见位置同步，以及收帚后双方状态和主机落地。此项与客机炫纹闭环一起通过，退出后两端角色、特效和粒子均为零，浏览器无错误。
