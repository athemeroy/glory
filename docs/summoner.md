# 召唤师：昧光与四兽流

核对日期：2026-10-03。本轮加入可选账号昧光（罗辑、兴欣），职业为召唤师。数值、容量、施法时间及模型均为本项目配置，不冒充小说给出的完整游戏规则。

## 原著核对

- 原著[第208章《召唤师》](https://demo.imwpweb.com/imwpclassic/6885.html)：印记能指挥召唤物；落在敌人身上转为攻击，落在队友身上转为跟随。指挥也需要操作，能选错目标。
- 原著[《我也能行》章节](https://czbooks.net/n/ai0283/aiff5?chapterNumber=1343)及[《给自己写份攻略》](https://cn.ttkan.co/novel/pagea/quanzhigaoshou-hudielan_1339.html)：四兽分别为灵猫、冰狼、雷鹰、小飞龙；对应暗、冰、光、火。灵猫的警戒范围较大；雷鹰在空中使用落雷。召唤物可以自主索敌，也可以由玩家指挥。不同转载网站有章号/章名错位，以正文内容交叉核对。
- 原著[第1354章《暗夜系的对决》](https://cn.ttkan.co/novel/pagea/quanzhigaoshou-hudielan_1355.html)：自由攻击、防守与玩家反复指令是不同的控制层次。
- 原著[第1370章《打得不错》](https://cn.ttkan.co/novel/pagea/quanzhigaoshou-hudielan_1371.html)：四兽俱在及站位是发动阵的前提；强化后的召唤兽仍能被杀，阵期间不能用重召替换，时限结束四兽消失。
- 原著[第1569章《舍命一击》](https://cn.ttkan.co/novel/pagea/quanzhigaoshou-hudielan_1570.html)：召唤物有存在时间，同种重新召唤可以替换旧实体，攻击者也能主动拦杀召唤兽。
- [读者职业整理](https://www.cnblogs.com/ssf-lrk/p/11350365.html)与[昧光资料](https://moegirl.uk/%E6%98%A7%E5%85%89)仅作检索辅助。未采用《全职高手：一剑风雷变》等同人的新增设定。

## 本轮可玩行为

| 槽位 | 招式 | 当前作用 |
| --- | --- | --- |
| s1 | 灵猫 | 跑动、警戒与真实低位扑咬，快速但血量较低 |
| s2 | 冰狼 | 较高血量，真实近身撕咬与短减速 |
| s3 | 雷鹰 | 在空中移动，从嘴部发射可被墙体拦住的落雷弹道 |
| s4 | 小飞龙 | 空中保持距离，火球命中产生短灼烧 |
| s5 | 印记 | 视线选敌集火、选队友跟随、选地面驻守；无穿墙锁定或宠物瞬移 |
| s6 | 跟随 | 撤回自身身边并停止主动攻击，再次操作恢复自由攻击 |
| ult | 兽王四元素阵 | 四种活兽都在18米内时可发动，强化12秒，封印重召，结束全部消失 |

四兽各有独立生命、真实高度/体积、移动和出手前摇。每种同时一只，重召替换；平时存在32秒。主人阵亡、重置、离场、切关或退出会清理。实体死亡不触发玩家死亡、回合结束、Boss波次或玩家击杀数。地面兽够不到高空目标；空中兽能被真实对空攻击击杀。扑咬及弹体起点取自当帧可见模型的嘴部插槽，随移动、转向和俯身更新；弹道按共享连续碰撞结算，对玩家的伤害归召唤者。

前摇结束才生成召唤物；被打断不会提前留下宠物。四兽阵缺少任一种时不会消耗法力或进入冷却。四兽阵伤害+45%、出手频率+30%、承伤-25%；这些全部为本作平衡值。主人基础远程伤害与生命低于其他法师，完整部署需要较多法力和吟唱时间。

模型为四足屈膝猫狼、层叠羽翼钩喙利爪的雷鹰，以及长吻角/翼膜骨指/弯尾的小飞龙，具有四足步态或振翼动画。躯干与头吻使用连续截面曲面，角尾沿曲线收尖；低饱和暗色主体、细微顶点毛色配局部元素发光，静态部件按材质合批。主人暂采用现有术士绑定资源派生，加独立玉色四元素胸饰与魔杖，未宣称新手工精模。`tools/summons-preview.html`提供统一灯光近景检查。

## 实现与边界

- `src/game/summons.js`：权威实体、指挥、寿命、移动、视觉和快照。
- `Combat.targets()`：人物加召唤物共用命中对象；`customHurtCapsules`提供兽身/兽头胶囊。召唤物保留在独立列表，避免污染胜负人数。
- LAN主机模拟，客机以同一快照延迟插值实体和血量；从最新快照恢复持续召唤，退出销毁资源。最近移除的身份短暂保留给延迟命中特效，防止客机重放找不到被击杀的兽。
- `player.summonState`：`count/max/mode/targetName/formation/pets`供HUD读取，mode包括free/focus/follow/guard/escort。
- 本轮是四兽流闭环。死亡骑士流、精灵合体/献祭、魔界之花、交替、独立逐兽操作尚未做；印记是即时视线选点的交互改编，四兽阵站位简化为有效距离，未声称完整重现职业技能树。

回归入口：`node --experimental-loader ./tools/three-local-loader.mjs tools/summons-regression.mjs`。真实浏览器/联机入口：`tools/check-summons.py`，使用局域网服务器与Mini Chrome/Metal。报告以`../artifacts/summons/`实际输出为准。

本轮验证：27项CPU回归、14项真实Fighter生命周期检查通过；实际两端LAN确认四种可见实体、受击死亡复制、延迟事件无回放错误及退出清理，浏览器错误为零。最终模型嘴点另有移动/转向后真实扑咬、弹体源点一致，以及两种地兽对高空挥空检查。这些检查验证机制和联机闭环，没有被当作职业胜率均衡的证明。
