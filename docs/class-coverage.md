## 可直接写入荣耀手册的操作摘要

1. 抛沙看眼睛和来向：对准正面眼部，转头能避开致盲。见原著机制第64章来源。
2. 遮影步是视野死角中的浮空追击，目标看见你就不成立。见第129/817章来源。
3. 圣火封的是技能，普通攻击仍可用；持续区域要绕开。见第233/234章来源。
4. 眩晕与僵直要分开：砖袭击头的眩晕受伤解除，攻击造成的物理硬直另算。见第976章来源。
5. 霸体仍会掉血，抓取能破其受击保护；不能把霸体当无敌。见第252/1341章来源。
6. 跑跳闪避需要管理体力，不应无限疾跑。见第1612章来源。
7. 印记是召唤师的战术指令：敌人集火，队友跟随，地面部署。见召唤师第208章来源。
8. 四兽各司其职，召唤物会死亡或到期，重新召唤替换同种。见《我也能行》/第1569章来源。
9. 兽王四元素阵有代价：四兽齐备后发动，期间不能补召，结束全部离场。见第1370章来源。

以上摘要说的是经原文确认的行为；对应本作的数值与简化必须在技能说明中单列。
