# 原著机制与客户端体验

2026-10-03 接续批次。入口仍为局域网 `http://192.168.31.6:8780/`；4090 保持关闭，实景验证使用 Mini 的 Chrome / Metal。

## 从原文核对行为

没有把用户举的几个技能作为完整需求清单。研究按职业、移动、命中、资源、状态和团队指令展开；读者职业表用于找线索，真正实施的行为回到小说章节核对。小说并未提供本作全部伤害、冷却、体力和弹道数值，配置数值与原著行为分开记录。

- [第7章《暗夜猫妖》](https://www.hetushu.com/book/171/118289.html)：第一人称、声音辨位与战斗无背景音乐。默认观察目标不自动转动相机；可选择的练习辅助不扩大命中范围。
- [第28章《职业水准的》](https://cn.ttkan.co/novel/pagea/quanzhigaoshou-hudielan_28.html)：连突两击、同位置触发隐藏出血，以及骷髅免疫出血。游戏使用真实目标局部接触点比较两击，18厘米容差、50%概率、出血数值是本作参数。
- [第941章《装备竞赛》](https://cn.ttkan.co/novel/pagea/quanzhigaoshou-hudielan_941.html)：纠正沐雨橙风“吞日”和索克萨尔“灭神的诅咒”的账号介绍；魔道扫把为“灭绝星尘”。名称核对不意味着旧武器模型已还原所有银武细节。
- [扫把掌握与空中施法](witch-flight.md)：独立起飞、升降、收帚、体力和失控坠落，AI与联机同步。
- [炫纹与斗者意志](battle-mage.md)：五类炫纹由对应真实接触生成，下一次接触打开手动发射机会，弹体命中才获得增益；连击升阶及新短连段降阶。
- [四兽、印记与兽王四元素阵](summoner.md)：四种有血量、寿命、体积的实体；敌人集火、队友跟随、地面部署。四兽阵期间不能补召，结束离场。
- [飞枪、飞炮与枪系操作](gunplay-and-combat-ui.md)：实际出膛产生反向物理冲量和本地抬枪；主机独算物理，访客重放反馈。实体弹下坠是用户要求的玩法取舍，不伪称小说原始参数。
- [猛虎乱舞与地裂斩](canon-physical-skills.md)：前者可持续移动转向且每击需接触；后者按真实落差放大落地冲击。
- [前轮状态、遮影步及体力依据](novel-mechanics.md)、[三维命中与遮挡](spatial-combat.md)继续生效。

## 让机制可以上手

大厅分为模式导航、当前账号预览和明确的开始按钮，记住账号和设置。进入准备页再选择账号、地图、对手或队伍，避免把全部选项同时铺满屏幕。账号可按系别过滤；技能详表按需展开，角色默认待机，主动点击才演示招式。团队替换重复账号时交换位置，第一位与当前出战账号一致。

桌面HUD把生命、法力、体力放左下，技能放底部，比分和目标放上方。触屏使用左摇杆、右侧普攻与技能区；次要动作收进“更多”。冷却、缺蓝、封印、吟唱和职业资源都有对应提示，多指操作独立释放。原有第一人称、越肩和第三人称切换保留。

第一人称跳跃另修复了相机落后身体的问题：相机直接跟随脚部世界高度，只平滑动作产生的相对眼高。正常跳跃/开枪的最高眼高差从21.4厘米降至7.3厘米；2米位置跳变时从1.406米降至约0.006米。没有改动身体网格或骨架，实际镜面与主相机的五组手臂绘制仍共用完全相同的几何和骨矩阵。证据在 `../artifacts/first-person-camera/`。

荣耀手册有操作、视野、职业、状态和团队五章，并能直接进入对应职业训练。训练目标按实际职业和当前配招生成，扫把、四兽、炫纹和飞枪有各自目标；只显示接下来三项，完成后递进。DPS读取实际造成伤害的累计差值，包含持续伤害与召唤兽贡献，而不是用技能面板基础数值冒充实伤。

设置按“操作与视角 / 画面 / 声音”分类。局域网大厅保留现有房间号邀请方式，玩家不需要阅读服务端启动命令。账号列表和HUD的13张头像由实际优化模型渲染，替换缩成小块的角色三视图；选角预览也尊重职业的模型来源，召唤师不会误回退成程序人。

从联机手册进入本地训练时会完整离开旧房间并解除重开局监听。训练中的招式配置使用草稿，取消或Esc不改存档；点击“应用并继续”才同步更新当前角色、存档、HUD与训练目标。

## 交付边界

当前13种可玩风格是12个转职职业加散人；并非原著24职业全部完成。完整覆盖清单见[职业覆盖](class-coverage.md)。魔道炼金完整体系、召唤师其他流派、战法75级第八阶与炫纹互撞等仍未完成；不会用换名或换颜色充数。

三章剧情为本作同人关卡，并非逐章复刻原著。当前角色沿用前轮 Blender 优化资产；召唤师是既有骨架衍生外观，四兽为程序化网格。生成模型的衣料、面部与部分姿势仍需要进一步美术制作，不能称为手工精模质量。

## 验证入口

- `tools/check-client-ux.py`：实际大厅、准备页、配队交换、剧情解锁、设置分类、手册跳转和训练目标；1440×900桌面、390×844及360×740竖屏、844×390横屏。
- `tools/render-class-avatars.py`：用同一 `CharViewer` 和优化骨架生成13张头像；渲染清单见 `../artifacts/class-avatars-20261003/manifest.json`。
- `tools/check-avatar-ux.py`：桌面/手机实际选昧光、检查优化绑定预览与头像、进入训练。
- `tools/check-lan-handbook-exit.py`：真实双端房间中，从客机手册转入训练、旧事件不能拉回；再验证配招取消与应用的一致性。浏览器零错误，证据 `../artifacts/lan-handbook-exit/`。
- `tools/check-combat-ui.py`：触控目标大小、布局、多指与取消、资源/读条反馈。
- `tools/check-witch-flight.py`、`tools/check-battle-mage.py`、`tools/check-summons.py`、`tools/check-height-skills.py`、`tools/check-gunplay-live.py`：实际角色和战斗系统。
- `tools/check-lan-class-mechanics.py`：真实房间两端的职业机制同步。
- `tools/check-balance.py`：固定种子、交换出生点的AI对战；用于发现明显机制问题，不等于真人竞技平衡证明。

本轮累计140场自动对战，按伤害归因小降魔道免费普攻和召唤总体伤害；同时修复AI失视后隔柱原地转圈、空中瞄准后忘记恢复平视。最终召唤专项8场5胜3负，停战专项8场全部结束；完整过程、数值和样本限制见[平衡报告](balance-20261003.md)。
